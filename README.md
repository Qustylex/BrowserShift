# BrowserShift

Switch browsers. Keep your flow.

Cross-platform terminal app that migrates bookmarks, history and cookies
between installed browsers. Auto-detects the OS.

Supported browsers: Chrome, Edge, Brave, Vivaldi, Opera, Opera GX, Firefox.

Cookie migration is fully implemented for Chromium -> Chromium and Firefox -> Chromium
on Windows (DPAPI + AES-GCM). Firefox on all platforms is plaintext.
